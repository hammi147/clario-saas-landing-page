# Clario — SaaS Landing Page

A modern, responsive SaaS landing page built with HTML, CSS, and JavaScript.

## Overview

Clario is a clean and professional landing page concept designed to showcase a SaaS product. It includes a modern hero section, feature highlights, workflow overview, pricing plans, FAQ accordion, and call-to-action sections.

## Features

- Responsive layout for desktop, tablet, and mobile
- Mobile navigation menu
- Interactive FAQ accordion
- Smooth scrolling navigation
- Modern dashboard-style illustration
- Pricing and call-to-action sections
- Dynamic footer year

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Status

Frontend demo project. Authentication, database integration, real payments, and backend functionality are not included.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the landing page and its interactive elements.
